# 任务 01 · Aevum 奢侈腕表品牌落地页

| 项目 | 内容 |
| --- | --- |
| 任务 | 为虚构奢侈腕表品牌 **Aevum** 制作一个精美的品牌落地页 |
| 交付文件 | `index.html`（单文件，约 89 KB / 1986 行） |
| 技术栈 | 原生 HTML + CSS + JavaScript |
| 外部依赖 | **零** —— 无外部图片、无字体、无第三方库、无网络请求 |
| 打开方式 | 双击 `index.html`，或拖进浏览器 |

## 约束核对

- [x] 只用 HTML / CSS / JavaScript
- [x] 不使用外部图片：腕表、机芯、表盘、技术蓝图全部为**内联 SVG / CSS 绘制**
- [x] 不使用外部库：字体走系统字体栈（Iowan Old Style / Georgia 等）
- [x] 零网络请求：唯一的 data URI 是浏览器标签页图标

## 页面结构

1. 顶部导航（滚动收缩、金色进度条、移动端抽屉菜单）
2. Hero —— 手工 SVG 腕表，**指针显示真实时间**，秒针连续扫秒，日期窗口显示今天
3. 规格跑马灯
4. Calibre AE-39 —— 齿轮组反向旋转、摆轮摆动、发条螺旋（全部 JS 生成）
5. Collection —— 三款表盘（Nocturne / Solstice / Meridian），10:10 经典摆位
6. **配置器** —— 表壳 / 表盘 / 表带实时换色换价（CSS 变量驱动 SVG）
7. 数字指标（滚动到视口时计数动画）
8. Atelier —— 技术蓝图自绘线条 + 创始人引言
9. 媒体报道、预约表单（含校验与成功态）、页脚

## 已验证
