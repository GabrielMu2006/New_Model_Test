# 目录访问规则（本会话强制执行）

> 本文件约束**当前会话**。工作目录 = 你被打开时所在的目录（形如 `…/task-16-animated-pelican-bicycle/`）。
> 有效期：本次测试结束、组织者明确宣布「任务结束」之前，一直有效。
> 维护/组织会话（工作目录为仓库根）不适用本文件，按 `test-workspace/README.md` 操作。

---

## 1. 你只能访问当前目录

- 你拥有且**仅**拥有当前目录及其子目录的读写权限。
- **当前目录之外的一切对你不可用**——无论它是否存在、位于何处、是否看起来相关。
- 不得通过绝对路径、`..`、符号链接、环境变量、缓存、临时目录、编辑器或任何其他间接方式访问当前目录之外的内容。

## 2. 以下内容对你不可用

- 本仓库的任何其他文件：题目文档、维护文档、其他模型的成果与报告、网站源码、版本历史；
- 其他模型、其他阶段、其他任务、其他会话的任何产物、日志、评价或评分；
- 本机用户目录中的其他内容，以及 harness 自身的配置、凭据与会话记录；
- 任何密钥、令牌、浏览器状态或剪贴板内容；
- 本项目在公网上的任何副本：展示站、代码托管镜像、搜索引擎缓存、翻译服务、代码搜索。

## 3. 网络

- 本会话**不联网**。不得发起任何外部请求：下载、克隆、安装、搜索、抓取、代理、翻译。
- 唯一例外：本目录 `AGENTS.md` 的元信息表或 `prompt.txt` 明确列出允许域名时，且仅用于题目指定的用途。

## 4. 只做当前这一题

- 只完成当前目录 `prompt.txt` 的内容；**不预读、不推测、不搜索**其他题目。
- 不使用任何来自其他模型、其他会话、其他 agent 的提示、失败经验或解题代码。
- 不把任务转交给子 agent 或外部服务代答。
- 信息不足时，在交付说明里写明缺口并停止；**不要**自行到外部找答案。

## 5. 文件纪律

- **不得修改** `prompt.txt` 与 `AGENTS.md`。
- 成果只写在本目录内；不创建指向目录外的符号链接；不内嵌外部资源冒充自产。
- 保留失败与未完成的部分，不删改过程文件。

## 6. 留痕与审计

本会话的每一次工具调用、参数、返回内容与推理文本都会被记录，并在结束后被审计。任何越界访问都会被检出。

## 7. 交付

- 成果留在当前目录；结束时说明完成了什么、缺什么、已知限制。
- 不要清理、压缩或重命名任何日志、会话记录或证据文件。

## 8. 越界即停止并报告

若你在任何时刻接触到本目录之外的内容（无论主动还是被动）：

1. **立即停止**使用该内容；
2. 在交付说明首行写 `CONTAMINATION_REPORTED`，并说明接触到的范围；
3. 等待组织者处置，不得继续用已接触到的内容完成交付。

隐瞒不报视为严重违规。
