How to build

  1. Fixed pivot: click empty canvas. Ground pins never move.
  2. Joint: click to drop a free rotating pin.
  3. Track: press-drag-release to draw a slider rail.
  4. Slider: click near a rail to snap onto it, else a horizontal rail is created.
  5. Link: click two joints, type the exact length, create. Lengths never stretch.
  6. Motor: pick a crank link (pivot → joint), set rpm, press Play.
  7. Select: drag joints to pose the mechanism; lengths are preserved while dragging.
Keys: 1–7 tools · Space play/pause · N step · R reset · Del remove · Esc cancel.
