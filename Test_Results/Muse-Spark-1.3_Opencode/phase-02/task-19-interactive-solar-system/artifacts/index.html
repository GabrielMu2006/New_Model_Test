How it works

One clock drives everything: simDays += dt × daysPerSecond. Each orbit angle is a pure function of simDays: angle = phase + 2π × simDays / periodDays. A moon's world position is planetPos(simDays) + moonOffset(simDays), so moons keep orbiting correctly while their planet travels, and moving the speed slider never jumps or loses orbital state.

Periods are real relative values (Earth 365.25 d, Jupiter 4332.6 d, Io 1.77 d, …). Sizes and distances are compressed for visibility and are not to scale.
