# Morrow Bank Website

A responsive, self-contained concept website for a modern consumer bank.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static file server.

## Included

- Responsive navigation and layouts for mobile, tablet, and desktop
- Keyboard-accessible product tabs and FAQ accordions
- Interactive five-year savings calculator
- Product, security, customer story, and conversion sections
- Reduced-motion support and semantic HTML

Morrow is a fictional bank. Rates and financial product details shown are illustrative.
