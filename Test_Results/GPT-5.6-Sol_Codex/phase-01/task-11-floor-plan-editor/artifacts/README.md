# Forma floor-plan editor

A dependency-free 2D floor-plan editor built with HTML, CSS, JavaScript, and SVG.

## Run

Open `index.html` directly, or serve this directory with any static server.

## Controls

- **Select (V):** select walls/openings; drag doors and windows along walls.
- **Wall (W):** drag to draw; the default is axis-aligned, and Shift enables free angles.
- **Door (D) / Window (N):** click an existing wall to place an opening.
- **Delete / Backspace:** remove the selected element.
- **Cmd/Ctrl+Z:** undo; **Cmd/Ctrl+Shift+Z:** redo.
- Use the properties panel to edit dimensions, thickness, and labels.
- Export downloads the current plan as an SVG.
