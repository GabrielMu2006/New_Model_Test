# Bitty Pixel Art Editor

A small, dependency-free 32×32 pixel-art editor that runs entirely in the browser.

## Run

Open `index.html` directly in a modern browser, or serve the folder with any static file server.

## Controls

- Pencil: `P`
- Eraser: `E` (or right-click while drawing)
- Undo: `Ctrl/Cmd + Z`
- Redo: `Ctrl/Cmd + Shift + Z` or `Ctrl/Cmd + Y`
- Export produces a transparent, native-resolution 32×32 PNG.
