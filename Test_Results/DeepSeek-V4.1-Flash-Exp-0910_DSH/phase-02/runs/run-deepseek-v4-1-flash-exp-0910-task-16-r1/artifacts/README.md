# task-16 — 会骑自行车的鹈鹕（动画 SVG）

## 交付物

**`pelican-bicycle.svg`** —— 单文件、无外部依赖、可直接双击在浏览器中打开的动画 SVG
（960×540，约 48 KB，纯 SMIL 动画 + 一段内联 JS 仅用于暂停/继续按钮）。

打开方式：

- 直接双击 / 拖进浏览器窗口（动画自动播放，左下角按钮可暂停与继续）；
- 或嵌入 HTML：`<img src="pelican-bicycle.svg">`（动画照常播放；此时内联脚本不执行，
  按钮点击无效——见「已知限制」）。

## 逐条对照题目要求

| 要求 | 实现 | 验证方式 |
| --- | --- | --- |
| 两个车轮自然转动 | 两轮各 `720° / 2s`（匀速），轮辐与气门嘴随轮旋转 | 渲染帧比对：轮辐区域 30–64% 像素变化；旋转量与地面位移一致 |
| 脚踏与曲柄转动 | 曲柄 `360° / 2s`；脚踏平台绕中轴公转（平台保持水平，符合真实脚踏） | 曲柄标记角度 180°/0.5s；曲柄区域 79% 像素变化 |
| 鹈鹕的脚始终踩在脚踏上 | 每 4° 解一次两段式 IK，脚踝 = 脚踏轴心 + (-2, -12)，作为关键帧烘焙进 SMIL | 注入彩色标记逐帧测量：9 个时刻脚踝−脚踏偏移恒为 (-2.0±0.2, -12.1±0.3) px |
| 双腿随脚踏自然运动 | 髋→膝→踝两段肢体，膝盖朝前弯曲，膝点约 58 px 垂直行程 | 膝关节位置逐帧计算；腿部区域 43%/12% 像素变化（近侧/远侧） |
| 身体细微响应踩踏 | 每转两拍的上下起伏 ±3.4 px、左右 ±1.2 px、滚转 ±1.15°，颈/头延迟点头、翅膀轻微颤动 | 身体区域 14%、颈头 32%、翅膀 26% 像素变化 |

## 运动学自洽性（为什么看起来「不滑」）

一个主循环 `T = 2.0 s` = 曲柄转一整圈：

- 牙盘 r=24 / 飞轮 r=12 → 传动比 2.0 → **车轮每循环正好转 2 圈**；
- 车轮半径 60 → 一个循环里轮胎接触点走过 `2 × 2π × 60 = 753.98 px`；
- 地面层在同一循环内位移 **正好 753.98 px** → 车轮与路面零打滑；
- 链条以牙盘线速度 75.4 px/s 沿闭合路径爬行（`stroke-dashoffset`，每循环 150.8 px = 12 个链节周期）；
- 远景 / 中景 / 云层用同一 753.98 px 位移、各自更长的循环（20 s / 6.25 s / 40 s）实现视差，
  且每层的瓦片内容按周期函数生成，循环首尾无缝。

所有关键帧在 Python 里按 4°（腿部）或 15°（身体）采样后写死进 SVG，浏览器端不需要任何计算。

## 验证方法（可复现）

```bash
./_build/run_all_checks.sh      # 需要 python3 + Pillow + Google Chrome
```

脚本依次检查：XML 合法性与内部引用 → 外部依赖 → 各层速度与主循环闭合 → 传动机构
（脚踝-脚踏偏移、曲柄/车轮角速度）→ 18 个区域的「该动的动、该静的静」审计 → 暂停/继续控件。

实测结论（`_build/checks.log`）：

- 去掉滚动层后 t=0 / 2.0 s / 4.0 s 三帧差异 93 px、51 px（518400 像素，0.018% 抗锯齿噪声）→ 循环闭合；
- 区域审计 18 项全部通过（16 项应动、2 项应静）；
- 暂停时 `getCurrentTime()` 增量 0.0000 s；继续后渲染帧与「始终暂停」对照相差约 5–7 万像素 → 确实恢复推进。

> 说明：`verify_pause.py` 走 `--dump-dom` 路径，该路径不产生渲染帧，SMIL 时钟不前进，
> 所以那里不测「继续后的时钟增量」；这项由 `verify_resume.py` 用渲染帧对照证明。

## 已知限制

1. **内联脚本只在「独立打开 / 内联嵌入」时生效**：把 SVG 放进 `<img>` 时浏览器不执行脚本，
   动画仍会播放，但按钮不响应。用 `<object>`、`<iframe>` 或直接打开则按钮正常。
2. **依赖 SMIL**：Chrome / Firefox / Safari 均支持；若某个极简 SVG 渲染器不支持 SMIL，
   会显示静止画面（文件里保留了首帧的 `d` / `transform` 静态属性作为回退）。
3. **脚踏平台保持水平**：这是真实自行车的物理行为（脚踏在轴上自由转动），
   公转体现在曲柄与脚踏的整体位置，而不是平台自身的倾角。
4. 未做 `prefers-reduced-motion` 处理（题目要求动画，默认即播放）。
5. 视觉细节（羽毛、光影）为卡通简化风格；检查环境只有无头 Chrome，
   Firefox / Safari 未做真机渲染验证。
6. 生成器与检查脚本保留在 `_build/`，是过程材料，不属于交付物；交付物只有
   `pelican-bicycle.svg` 一个文件。
