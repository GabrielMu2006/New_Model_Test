# 任务 08 · 霓虹打砖块（Breakout）

| 项目 | 内容 |
| --- | --- |
| 任务 | 用单个 HTML 文件做一个精致、可玩的打砖块游戏 |
| 交付文件 | `index.html` |
| 打开方式 | 双击文件，或拖进浏览器（无需服务器、无外部依赖） |
| 技术 | 原生 HTML / CSS / JavaScript + Canvas 2D + WebAudio |

## 玩法

| 操作 | 说明 |
| --- | --- |
| 鼠标 / 触摸移动 | 挡板跟随指针 |
| `←` `→` 或 `A` `D` | 键盘移动挡板 |
| `空格` / 点击画面 | 发球、开始、重新开始 |
| `P` / `Esc` | 暂停 / 继续 |
| `M` | 静音开关（右上角按钮同效） |

- 挡板不同位置接球会改变反弹角度，靠边缘接球可打出大角度。
- 连续击碎砖块累积**连击倍率**（最高 ×5），碰到挡板后重置。
- 击碎砖块有约 17% 概率掉落道具：
  - `W` 加宽挡板（20 秒）
  - `M` 三重球
  - `S` 慢动作（14 秒）
  - `♥` 额外生命
- 共 6 关，砖块从 4 行递增到 6 行，血量 1–3 级（青 / 紫 / 金），球速随关卡提升。

## 实现要点

- **固定步长物理**：120 Hz 累加器推进，每个子步再做一次移动子分步，避免高速穿模。
- **可预测的反弹**：按最小穿透深度决定反弹轴；同时限制球速方向，避免近乎水平的死循环（正中心接球会加极小随机偏移）。
- **纯合成音效**：WebAudio 实时生成，零音频文件；AudioContext 在首次用户交互后才创建。
- **性能**：砖块 / 背景 / 暗角全部预渲染成离屏精灵，每帧只做 `drawImage`；渲染按 devicePixelRatio 缩放，上限 2×。
- **自适应**：逻辑分辨率固定 900×640，容器用 CSS `aspect-ratio` + `dvh` 公式缩放，任何屏幕比例都完整可见，无滚动条。
- 关闭标签页或窗口失焦自动暂停；最高分存于 `localStorage`（隐私模式下自动降级）。

## 验证

用 Node 加桩件（stub 掉 DOM / Canvas）驱动真实游戏循环做了回归测试：

- 完美操作可依次通过全部 6 关并触发通关界面（实测终局 16,710 分）。
- 不接球会正常扣光生命并进入结束界面。
- 球速方向比值始终 ≥ 0.34，未出现水平卡死。
- 标题 / 暂停 / 结束 / 通关四种遮罩的 HTML 标签配平，HUD 数值同步正确。
- 用 headless Chrome 在 1240×940、1400×600、420×860 三种视口截图确认无裁切与溢出。
