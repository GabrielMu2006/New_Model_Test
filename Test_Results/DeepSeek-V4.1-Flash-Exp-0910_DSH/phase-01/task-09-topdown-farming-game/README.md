# 任务 09 · 山谷农场（Harvest Hollow）

| 项目 | 内容 |
| --- | --- |
| 任务 | 用单个 HTML 文件做一个精致、可玩的俯视角农场经营游戏 |
| 交付文件 | `index.html` |
| 打开方式 | 双击文件，或拖进浏览器（无需服务器、无外部依赖） |
| 技术 | 原生 HTML / CSS / JavaScript + Canvas 2D + WebAudio |

## 玩法

| 操作 | 说明 |
| --- | --- |
| `WASD` / `↑↓←→` | 移动 |
| `空格` / `E` | 使用当前工具、交互（开门、睡觉、打水、收获） |
| 鼠标点击地块 | 同样可以操作，需站在两格以内 |
| `1` / `2` / `3` | 锄头 / 水壶 / 种子 |
| `Q` / `Tab` | 切换种子种类 |
| `M` | 静音；`Esc` 暂停 |

核心循环：**翻地 → 播种 → 每天浇水 → 隔夜生长 → 收获 → 卖给杂货铺**。

- 只有当天浇过水的作物才会在隔夜长一天；没浇水就完全不长。
- 水壶容量 20，走到池塘边按空格打水，不消耗体力。
- 雨天（每天 26% 概率）会自动给整块地浇水，可以偷懒。
- 一天从 6:00 开始；撑到凌晨 2:00 会昏倒，扣 $20 且次日只有一半体力。
- 体力：翻地 −2，浇水 / 播种 / 收获 −1。回屋门按空格睡觉，第二天满体力。
- 作物：芜菁（2 天 / $20→$45）、胡萝卜（3 天 / $35→$85）、番茄（4 天 / $55→$160）、南瓜（5 天 / $100→$320）。
- 进度自动存在 `localStorage`，睡觉、买卖、关闭页面时都会写档。

## 实现要点

- **地形离屏预渲染**：草地、水面、小路、建筑（墙 / 屋顶 / 窗 / 门）只在启动时画进离屏 canvas，每帧只重绘土壤、作物、角色和特效。
- **程序化像素美术**：所有画面零贴图、零外部资源，用 `fillRect` / `ellipse` / 曲线拼出来；草地用哈希噪声生成纹理与小花，水面叠加流动高光。
- **昼夜与天气**：色调用关键帧插值（清晨暖橙 → 白天无色 → 黄昏 → 深夜深蓝），夜里门窗透出暖光并叠加暗角；雨天有斜线雨丝与冷色调。
- **y 轴排序**：树和角色按脚底 y 排序绘制，角色可以正确走到树后面。
- **建筑即交互点**：房屋和商店是实心带屋顶的体块，门前按空格触发睡觉 / 开店，省掉内部地图。
- **音效全部合成**：WebAudio 实时生成（翻地噪声、浇水、收获双音、金币、睡觉和弦），无音频文件，首次交互后才创建 AudioContext。
- **自适应缩放**：逻辑分辨率固定 768×512，外层容器整体 `transform: scale()`，HUD 文字矢量缩放不失真。

## 验证

用 Node + DOM/Canvas 桩件驱动**真实游戏循环**做了 61 项回归测试（`/tmp/hh-test.js`），覆盖：

- 标题 → 新游戏 → 锄地 / 播种 / 浇水 / 收获的完整链路，体力与种子数逐项核对；
- 重复浇水被拒绝且不扣体力；水壶在池塘补满且不扣体力；
- 睡觉换日、体力恢复、雨/晴天气、存档写入与 JSON 合法性；
- **浇水机制**：连续两天不浇水 → 作物不成熟、无法收获；连续两天浇水 → 可收获；
- 熬到凌晨 2:00 昏倒 → 扣 $20、次日体力 50%；
- 商店买入 / 卖出金额与库存同步；
- 暂停时游戏时间冻结；地图边界移动；4000 帧随机按键无异常。

测试期间发现并修复了 3 个真实缺陷：`fee` 变量作用域错误（昏倒换日时崩溃）、游戏时钟累加器被重复累加（时间走得比预期快一倍）、满体力时无法睡觉导致第二天开局卡死。

另外用 headless Chrome 截图 + 纯 Python PNG 解码，按坐标核对了水面、草地、小路、两种屋顶、干/湿土壤的渲染颜色与 HUD 面板几何位置。
