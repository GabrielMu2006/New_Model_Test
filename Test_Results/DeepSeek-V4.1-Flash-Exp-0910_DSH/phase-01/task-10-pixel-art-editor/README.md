# 任务 10 · 像素画编辑器（Pixel Art Editor）

| 项目 | 内容 |
| --- | --- |
| 任务 | 用单个 HTML 文件做一个精致的像素画编辑器 |
| 交付文件 | `index.html` |
| 打开方式 | 双击文件，或拖进浏览器（无需服务器、无外部依赖） |
| 技术 | 原生 HTML / CSS / JavaScript + Canvas 2D |

## 功能

| 功能 | 说明 |
| --- | --- |
| 绘制 | 铅笔工具，按住拖动连续绘制；快速拖动也不会断点（Bresenham 插值） |
| 擦除 | 橡皮工具擦成**透明**（不是涂白），导出 PNG 保留 alpha；右键拖动随时擦除 |
| 取色 | 油漆桶旁的取色工具，或 `Alt` + 点击直接从画布吸取颜色 |
| 填充 | 油漆桶，点击连通区域一次性上色 |
| 颜色选择 | 24 色调色板 + 系统取色器 + 最近使用色；点击大色块打开取色器 |
| 画笔大小 | 1–8 px 滑块，方形 / 圆形两种笔尖，左侧有实时笔尖预览 |
| 撤销 / 重做 | 60 步历史，`⌘/Ctrl+Z` 与 `⌘/Ctrl+Shift+Z`；按钮在无历史时自动置灰 |
| 缩放 | 1×–64× 档位缩放，`−` / `+` 按钮与键盘、`Ctrl/⌘+滚轮` 以光标为锚点缩放、`0` 一键适应窗口 |
| 导出 PNG | 1×/2×/4×/8×/16× 倍率，最近邻放大不糊边；文件名自动带尺寸与时间戳 |
| 其它 | 画布 16–128 px 可调、网格开关、背景（透明棋盘 / 白 / 黑）、`localStorage` 自动存档 |

## 操作

| 操作 | 说明 |
| --- | --- |
| 左键拖动 | 用当前工具绘制 |
| 右键拖动 | 临时切换到橡皮 |
| `Alt` + 点击 | 临时切换到取色 |
| `B` / `E` / `G` / `I` | 铅笔 / 橡皮 / 填充 / 取色 |
| `[` / `]` | 画笔缩小 / 放大 |
| `−` / `+` / `0` | 缩小 / 放大 / 适应窗口 |
| `⌘/Ctrl + Z` | 撤销；加 `Shift` 或 `Ctrl+Y` 重做 |
| `⌘/Ctrl + S` | 导出 PNG |
| `Ctrl/⌘ + 滚轮` | 以光标为中心缩放（普通滚轮仍是滚动） |

## 实现要点

- **离屏画布即唯一数据源**：逻辑像素 1:1 画在一张离屏 `canvas` 上，显示层只负责按 `zoom` 缩放绘制（`imageSmoothingEnabled = false`），所以缩放到 6400% 也依然是硬边像素，不会插值发虚。
- **双层渲染**：显示层画棋盘背景 + 像素画；叠加层单独画网格和笔尖预览。鼠标移动时只重绘叠加层，绘制时也不会把网格线画进图里。
- **笔尖遮罩**：按尺寸与形状生成偏移表并缓存。圆形笔尖用半径 `(s−1)/2 + 0.25` 判定，尺寸 3 得到的是十字形而不是一个方块。
- **橡皮即透明**：使用 `globalCompositeOperation = 'destination-out'`，擦除后该像素 alpha 为 0，导出 PNG 时保留透明通道（测试中直接核对过 `alpha = 0`）。
- **洪水填充不递归**：用显式栈 + `Uint8Array` 去重，128×128 也不会爆栈；目标色与填充色相同时直接返回。
- **撤销栈**：整画布 `ImageData` 快照，上限 60 步，内存可控；每次新操作会清空重做栈，符合常规编辑器直觉。
- **缩放档位可逆**：缩放级别取自固定档位表，适应窗口时会**吸附到档位**，因此 `+` 之后再 `−` 一定回到原级别；光标锚点缩放通过换算 `scrollLeft/scrollTop` 实现。
- **存档容错**：`localStorage` 读写全部包在 `try/catch` 里，在 `file://` 或隐私模式下不可用时自动降级为“不存档”，编辑器功能不受影响。
- **触屏友好**：全部用 Pointer Events + `touch-action: none`，平板可直接用手指画；640 px 以下工具栏自动换行。

## 验证

用 Node 直连 headless Chrome 的 DevTools Protocol，派发**真实鼠标 / 键盘 / 滚轮事件**并逐像素核对画布数据，共 **40 项**检查全部通过（脚本：`/tmp/px-verify.cjs`）：

- 铅笔起笔 / 落笔 / 拖动中间点像素颜色与 alpha 逐一核对，未触碰的像素保持透明；
- 3 px 画笔正好覆盖 3×3 且不越界；圆形笔尖不越界；
- 橡皮擦成 `alpha = 0` 且不误伤相邻像素；右键拖动擦除同样生效；
- 撤销 / 重做来回切换后像素状态正确，历史耗尽时重做按钮置灰；
- `Alt` + 点击取色把当前色改成画布上的颜色；油漆桶把 8×8 画布整块填满（64 像素计数）；
- 缩放：适应窗口落在档位上、`+` 与 `−` 可逆、显示层与叠加层尺寸随缩放同步、键盘 `+` / `0` 生效、`Ctrl+滚轮` 放大后能缩回；
- 导出：真实下载落盘，校验 PNG 签名、IHDR 尺寸（1× = 16×16，4× = 64×64）与文件名规则；
- 刷新页面后作品与设置从 `localStorage` 完整恢复。

测试中发现并修复了 2 个真实缺陷：适应窗口得到的缩放值不在档位表上，导致 `+` 之后再 `−` 回不到原级别（已改为吸附档位）；430 px 窄屏下顶部工具栏溢出（已改为换行 + 精简状态栏）。

另外用 headless Chrome 在 1280 / 820 / 430 px 三种宽度下截图核对布局，确认无横向溢出、无裁切重叠。
